# Curso de Desarrollo Web para principiantes
## Fundamentos de Desarrollo Web

La carpeta **starter_files** incluye archivos para partir, respectivos a cada lección.
La carpeta **completed_examples** incluye archivos con ejemplos completos a partir de cada lección de desarrollo.
La carpeta **scripts** corresponde a las transcripciones en texto de cada video de las lecciones.

No es necesaria la configuración de los archivos para seguir las lecciones, únicamente se utiliza el editor de código codepen.io
