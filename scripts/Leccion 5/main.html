¡Hola a todos! Hoy vamos a crear nuestra primera página completa: una página de perfil. No vamos a necesitar instalar nada extra. Todo lo vamos a usar mediante CodePen, una herramienta gratuita que se abre desde el navegador y que puedes usar sin crear una cuenta nueva. Vamos a usar HTML y CSS. Vamos a empezar creando el título. Escribimos «Mi página de perfil» y cerramos la etiqueta. Debajo va a haber una imagen, con la etiqueta img. Esta contiene el atributo src, que es la dirección de la imagen. En este caso lo dejamos vacío; más adelante pondremos la dirección. Además, usamos el atributo alt, que es un texto alternativo que describe la foto y que puede servir cuando una persona no puede cargar completamente la imagen. Luego vamos a poner un subtítulo con la etiqueta h2. Escribimos «¡Hola, qué gusto verte!» y cerramos. Debajo colocamos un párrafo con la etiqueta p, que diga: «Esta es mi primera página web y la hice con HTML y CSS». Ponemos un punto y cerramos la etiqueta. Fíjate que la etiqueta de cierre siempre lleva una barra al inicio, como en la etiqueta p. Este es el resultado que tenemos por el momento: el título, un subtítulo y un párrafo, y la imagen que se agregará después. Esto ya se puede considerar una página web, aunque todavía se ve muy sencilla. Lo vamos a cambiar usando CSS. Vamos a empezar por body, que representa todo el contenido visible de la página. Primero colocamos font-family para elegir la fuente, que será Verdana, seguida de sans-serif. Luego usamos background-color para el color de fondo, que va a ser un azul grisáceo. Colocamos el código #eef2f7. Ese código con almohadilla, o símbolo de michi, está en hexadecimal y representa cuánto hay de rojo, verde y azul en el color. Después ponemos text-align: center; para que el texto quede alineado, y por último padding: 40px;. Recuerda que cada línea de CSS termina con punto y coma; si no, las propiedades que estás poniendo pueden no ejecutarse correctamente. El texto ya está centrado, hay un espacio a los lados y la letra se ve más grande y agradable. Vamos a seguir con los títulos h1: les damos un color azul oscuro con la propiedad color. Colocamos h1, abrimos las llaves y escribimos color y el código #1f3a5f. Esperamos unos segundos y ya se cambia el color. Ahora, la imagen. Con el selector img empezamos dándole un ancho y un alto de aproximadamente 160px. Colocamos img, abrimos las llaves y ponemos width, que es el ancho. Después ponemos la altura, height, también de 160px. Vamos a usar object-fit: cover; para que la foto se recorte sin deformarse y se vea bien. Escribimos object-fit y ponemos cover. Luego añadimos border-radius: 50%;, que la convierte en un círculo. Finalmente, le ponemos un borde con border. Esta propiedad necesita tres valores seguidos: primero, el grosor, 4px; luego, el tipo de línea, solid; y el mismo azul del título. Podemos copiar y pegar el código #1f3a5f. Terminamos con punto y coma para mantener la consistencia. Así iría quedando. Como ves, todavía no hay una imagen dentro, pero el borde ya se nota. Por último, vamos a darle estilo al párrafo. Ponemos el selector p y un max-width de 420px. Esto evita que el texto se estire demasiado si escribimos bastante. Luego, con margin, dejamos 20px de separación arriba y abajo y lo centramos a los lados con auto. Con color usamos un gris suave en lugar del negro: el código #4a5568. Ahora vamos a agregar el enlace de la imagen en src. En este caso usamos el enlace que aparece en pantalla. Debería cargar. Listo. Con esto ya tienes tu primera página completa. Puedes compartirla copiando el enlace de tu proyecto en CodePen. Espero que te haya servido bastante. Con eso estaría terminado todo.
