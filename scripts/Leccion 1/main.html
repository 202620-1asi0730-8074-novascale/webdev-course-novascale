¿Alguna vez has abierto una página y pensado: yo también quiero crear algo así? Imagina una web para tu equipo de videojuegos, para mostrar tus dibujos o para organizar un club de tu colegio. No necesitas empezar con algo gigante. Hoy vas a descubrir qué es una página web, cómo llega a tu pantalla y qué hacen las tres tecnologías que aparecen por todas partes: HTML, CSS y JavaScript. Al final tendrás una pequeña misión. Solo necesitas un navegador, conexión a internet y ganas de experimentar. Vamos paso a paso. Empecemos por una diferencia que suele confundir. Una página web es un documento que puedes abrir con un navegador. Puede tener texto, imágenes, videos y enlaces. Un sitio web reúne páginas relacionadas, aunque también puede tener una sola. Piensa en la web de un club: una página presenta al equipo, otra muestra sus actividades y otra explica cómo participar. Cada una es una página; juntas forman el sitio. Los enlaces te permiten pasar de una a otra. Es parecido a un libro con varias hojas, pero aquí puedes elegir tu propio recorrido. Y sí, esa página también puede verse desde un celular. Ahora viene lo interesante. Escribes una dirección y aparece una página. No sucede por magia. Tu navegador solicita información a un servidor: otra computadora que puede enviar los archivos de un sitio. La respuesta viaja por la red y el navegador interpreta esos archivos para mostrarte el resultado. Esta es una explicación simplificada, pero la idea clave es pedir, recibir y mostrar. Además, internet y la web no significan exactamente lo mismo. Internet es la red que conecta dispositivos. La web es uno de los servicios que funcionan sobre esa red. Y el navegador es el programa con el que visitas las páginas. Una página combina tres tecnologías con trabajos diferentes. HTML organiza el contenido y le da significado. CSS define su presentación: colores, tamaños, espacios y distribución. JavaScript permite programar comportamientos, como actualizar un marcador sin recargar la página. Imagina una tarjeta de tu club. El título y la descripción son contenido. Los colores y la forma son presentación. Un contador que cambia al pulsar un botón es comportamiento. Son piezas que se complementan. Empecemos por HTML. Es un lenguaje de marcado: indica qué representa cada parte del contenido. Esto es un título, esto es un párrafo y esto es un enlace. No se trata solo de poner letras grandes. Se trata de organizar la información y darle significado. En nuestra página del club, el título presenta la idea, el párrafo la explica y un enlace puede llevar a otra página. Primero decide qué quieres comunicar. Esa estructura es la base. Ahora imagina esa misma tarjeta con un fondo azul, un título claro y más espacio alrededor del texto. El contenido no cambió, pero se siente diferente. Ahí entra CSS, un lenguaje de estilos. Nos permite decidir cómo se presenta el contenido: el color, la tipografía, los bordes y la distribución. También ayuda a adaptar el diseño a pantallas de distintos tamaños. Un detalle importante: que algo se vea bonito no basta. Debe poder leerse. Usa un buen contraste, deja espacio y evita letras diminutas. Diseñar una web también significa pensar en la persona que la va a usar. ¿Y si queremos que la tarjeta responda? Por ejemplo, pulsas un botón y aumenta el número de puntos del club. Ese cambio puede programarse con JavaScript. Aquí sí estamos hablando de un lenguaje de programación. Ojo: no todos los enlaces ni todos los efectos necesitan JavaScript. Un enlace normal ya puede funcionar con HTML, y muchos efectos visuales pueden hacerse con CSS. Para empezar, no hace falta un juego completo ni un sistema de cuentas. Una página sencilla con contenido claro y estilos cuidados ya es un proyecto real. Primero entiende las piezas; luego las combinas. Probemos la idea en JSFiddle, un editor en línea. No necesitas instalar nada. En el panel de HTML escribimos el título y una descripción. Al ejecutar, aparecen en el resultado. Después añadimos CSS: cambiamos el fondo, el color del título y los bordes. Ejecutamos otra vez. Es la misma información, pero ahora tiene un diseño propio. Tu turno. Imagina una página sobre algo que te guste. Elige un título, escribe una descripción corta y piensa en dos colores fáciles de leer. Si abriste el ejemplo, cambia esos datos y observa el resultado. Puedes usar un club inventado. Pausa el video el tiempo que necesites para probar tu idea. Un reto para cerrar. ¿Cambiar el contenido? HTML. ¿Modificar los colores y la distribución? CSS. ¿Programar un contador que responda a un clic? JavaScript. Crear una web empieza con una idea pequeña: organizar lo que quieres contar, darle forma y probar cómo funciona. Ya conoces las piezas. Ahora puedes empezar a experimentar.
