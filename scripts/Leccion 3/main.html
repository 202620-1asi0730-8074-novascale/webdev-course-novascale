Hola, futuro programador. Hoy vas a crear una reseña de Minecraft escribiendo código. HTML es el esqueleto de toda página web y se construye con etiquetas. Abre CodePen y mira el panel vacío. Una vez dentro del nuevo proyecto, cerraremos todas las pestañas menos el de HTML. Empecemos con los encabezados. La etiqueta H1 es el título principal. Se abre con H1, se escribe el texto y se cierra con una barra. Escribe reseña de Minecraft. Hay seis niveles de H1 a H6. Mientras más grande el número, más pequeño es el título. Mira cómo se ven. Si tu título es H6, hasta un creeper lo ignora. Ahora, el párrafo. La etiqueta P sirve para escribir texto normal. Es perfecta para dar tu opinión. Escribe, Minecraft es un mundo de bloques donde puedes construir, explorar y sobrevivir. Puedes usar todos los párrafos que quieras. Escribe un segundo, mi parte favorita es el modo supervivencia. Fíjate que cada párrafo empieza en una línea nueva. Llegó la hora de las listas. Imagina que acabas de aparecer en mundo nuevo y no tienes nada. ¿Qué necesitas? Un inventario. En HTML, para hacer una lista con viñetas usamos la etiqueta UL. UL significa lista sin orden, porque no importa cuál va primero. Ahora escribe un título, materiales básicos. Ahora cada objeto de la lista va dentro de una etiqueta LI, que significa elemento de la lista. Escribe madera, porque con ella haces tu mesa de crafteo. Piedra, para picos más fuertes y para el horno. Hierro, que te da armadura y herramientas resistentes. Y diamante, el tesoro más brillante que casi nunca encuentras. Mira cómo aparece tu inventario con viñetas. Ahora veremos la lista ordenada con OL. Sirve cuando el orden sí importa, como una receta o los pasos para sobrevivir tu primera noche. Escribe el título, tu primera noche. Primero, recoge madera. Segundo, construye un refugio. Tercero, espera al amanecer. ¿Notaste algo? No escribimos los números, el navegador los pone solo. Si cambias el orden de los pasos, los números se arreglan solos. Quinta etiqueta, las imágenes con IMG. Sirve para mostrar capturas, dibujos o fotos, porque una reseña sin imágenes es aburrida. Es especial, no lleva etiqueta de cierre. Y usa atributos que son ajustes dentro de la etiqueta. SRC guarda la dirección de la imagen. ALT es un texto que describe la foto para quien no puede verla. Y WIDTH controla el ancho en píxeles. Escríbelos y mira cómo aparece tu paisaje. Sexta y última etiqueta, los enlaces con la letra sirve para viajar de una página a otra, como un portal de Minecraft. Escribe el texto que se verá, visita el sitio oficial de Minecraft. El atributo H R E F guarda la dirección a la que viajas al hacer clic, minecraft.net. Truco. Una imagen dentro de la etiqueta también funciona como enlace. Pasa el mouse sobre ellos. Reseña terminada. Repasemos, H 1 a H 6 para títulos. P para párrafos. U L y O L para listas. I M G para imágenes. Y A para enlaces. Con solo seis tipos de etiquetas ya armaste una página completa.
