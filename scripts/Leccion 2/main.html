Hola a todos. En esta lección aprenderemos la estructura básica de HTML. A través de esta sesión, comprenderemos paso a paso cómo se construyen las bases fundamentales de las páginas web en internet. Es importante destacar que el resultado final que interpreta cualquier navegador siempre será código HTML puro, por lo que dominar estos conceptos es un requisito indispensable para cualquier futuro desarrollador. Para comprender este concepto, debemos definir exactamente qué es HTML. Por sus siglas en inglés, significa Lenguaje de Marcado de Hipertexto, y es el estándar universal utilizado para organizar y presentar el contenido en internet. A diferencia de lenguajes como Python o Java, HTML no ejecuta lógica ni operaciones matemáticas. Este lenguaje actúa exclusivamente como el esqueleto estructural de todo sitio web. La estructura HTML se sostiene sobre tres conceptos. El primero son las etiquetas. Estas actúan únicamente como los marcadores o cascarones vacíos del documento. Como pueden ver en pantalla, tenemos como ejemplo el comando h1 que sirve para indicarle al navegador dónde inicia y dónde termina un bloque, y siempre deben escribirse encerradas entre los símbolos de menor que y mayor que. Nuestro segundo concepto son los elementos. Es un error muy común confundir una etiqueta con un elemento. Como observan ahora, el elemento es la anatomía completa: abarca desde la etiqueta de apertura, pasando por el texto o contenido interno que deseamos mostrar, hasta llegar a la etiqueta de cierre. Es decir, el elemento es el bloque ya rellenado y listo para ser procesado. El tercer componente son los atributos. Estos funcionan como instrucciones adicionales que se añaden exclusivamente dentro de la etiqueta de apertura para extender su comportamiento predeterminado. Por ejemplo, al agregar el atributo lang dentro de la etiqueta html, somos capaces de indicarle explícitamente al navegador y a los motores de búsqueda que el idioma principal de nuestro documento será el español. Toda página web moderna requiere iniciar con una envoltura principal. En primer lugar, utilizamos la declaración Doc type, la cual se redacta comenzando con un signo de exclamación para indicarle al navegador que usamos el estándar HTML más reciente. Posteriormente, encerramos absolutamente todo nuestro trabajo dentro de una etiqueta maestra denominada HTML. Todo el contenido de la página existirá en su interior. Finalmente, dentro de esa etiqueta principal, es estrictamente necesario dividir la página en dos grandes secciones. La primera sección es el Head, o cabeza. Este espacio funciona como el área técnica del sitio, donde se colocan metadatos y configuraciones invisibles para el visitante. La segunda sección es el Body, o cuerpo. Absolutamente todo el contenido que redactemos dentro del Body será renderizado en la interfaz gráfica, siendo exactamente lo que el usuario final podrá leer e interactuar. Con esto concluimos la explicación teórica de nuestra clase. Ahora, ha llegado el momento de aplicar estos conceptos directamente en la práctica. Para esta demostración utilizaremos CodePen, un editor de código en línea sumamente popular y accesible. Como pueden observar en pantalla, la interfaz nos ofrece un panel principal donde ya contamos con una estructura base predefinida, y un panel donde veremos el resultado gráfico renderizado en tiempo real. Antes de escribir nuevo código, analicemos la estructura de inicio que tenemos en pantalla. En la primera línea encontramos la declaración Doc type, seguida de la palabra html. Esto le indica al navegador que debe interpretar nuestro proyecto utilizando la versión más reciente del estándar, conocida como HTML cinco. Inmediatamente debajo, tenemos abierta nuestra etiqueta maestra html, la cual incluye el atributo lang configurado en español. Si revisamos la parte inferior del documento, veremos su respectiva etiqueta de cierre. Todo nuestro sitio web vivirá estrictamente dentro de este contenedor principal. Vamos a comenzar a trabajar dentro de la etiqueta head. Recuerden muy bien que esta es el área técnica y de configuración del documento. Todo lo que escribamos en este bloque será invisible en la interfaz gráfica, pero resulta vital para el navegador. Dentro del espacio vacío de nuestro head, escribiremos una etiqueta meta. A esta etiqueta le asignaremos el atributo charset, igualado al valor U T F 8. Al ser una etiqueta de autocierre, no requiere de una contraparte final. Esta configuración técnica específica es la que nos garantiza poder utilizar caracteres propios del español, como la letra eñe o las tildes, evitando errores visuales en la página. En la siguiente línea, agregaremos la etiqueta title. Abriremos la etiqueta, escribiremos el texto Apuntes de HTML, y finalmente la cerraremos. Este texto será exactamente el nombre que aparecerá en la pestaña superior de nuestro navegador web cuando un usuario visite el sitio. Con esto, hemos concluido la configuración inicial técnica. Ahora, dirigimos nuestra atención al interior de la etiqueta body. A partir de este preciso momento, todo el código y los textos que redactemos formarán parte del área gráfica. Es decir, será exactamente lo que los visitantes consumirán e interactuarán en sus pantallas. Comenzaremos a llenar nuestra página agregando un título principal. Para lograr esto, utilizamos la etiqueta h 1, que en la jerarquía de este lenguaje representa el nivel de encabezado más grande y de mayor importancia. Rellenamos el interior de este elemento con el texto: Mi primera página. Si necesitamos crear divisiones, subtítulos o secciones secundarias, debemos utilizar los siguientes niveles de encabezados, como las etiquetas h 2 o h 3. En la siguiente línea abriremos una etiqueta h 2 y, en su interior, formularemos la siguiente interrogante de estudio: ¿Qué es un elemento?. Para responder a esta pregunta y darle cuerpo a nuestros apuntes, utilizaremos la etiqueta p, la cual sirve específicamente para estructurar bloques de párrafo estándar. En su interior redactaremos nuestra respuesta formal: Un elemento contiene una etiqueta de apertura, su respectivo contenido interno, y finaliza con su etiqueta de cierre. Si dirigimos nuestra atención al panel de vista previa gráfica, notaremos que el navegador ha procesado e interpretado perfectamente todas y cada una de nuestras etiquetas. Ha transformado nuestro código plano en una estructura visual real, correctamente jerarquizada y completamente funcional. Felicidades por llegar hasta aquí.
