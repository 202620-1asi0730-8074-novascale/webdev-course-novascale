¡Hola! Te doy la bienvenida a esta lección de CSS. Como ves, tengo un editor en línea con dos pestañas importantes: una para el código HTML y otra para CSS. CSS viene del inglés «Cascading Style Sheets», u «hojas de estilo en cascada», y sirve para dar apariencia a lo que creamos con HTML, como los colores, el tipo de letra y los tamaños. Vamos a verlo con un ejemplo. Vamos a escribir en HTML un título y un párrafo. En el título ponemos «Bienvenido a mi página», y como párrafo, «Aquí escribo un texto sencillo para practicar». Fíjate que se ve bastante básico: solamente letras negras sobre un fondo blanco, sin ningún diseño. Funciona, pero se ve muy aburrido. Ahí es donde entra CSS. Una regla de CSS tiene tres partes. La primera es el selector, que indica a qué elemento de HTML le vas a dar estilo. Luego están las llaves y, dentro de ellas, las propiedades. Cada propiedad lleva un nombre, le siguen dos puntos, después un valor y termina con punto y coma. Vamos a usar h1 como selector para editar el título. Lo colocamos, ponemos las llaves y dejamos un espacio. En este caso vamos a poner la propiedad color, con el valor red, que es rojo, para cambiar el color de las letras del título. Como se puede ver, ya cambió. Ahora vamos a agregar otra propiedad, font-family, que cambia el tipo de letra. La escribimos y ponemos Arial. Por último, vamos a poner font-size, que cambia el tamaño. En este caso colocamos 55px. Los px son píxeles. El título se va a ver grande y se ve bien. Tú puedes variar los colores, el tipo de letra y los píxeles. Para continuar, colocamos el selector p, que indica los párrafos de nuestro HTML, y abrimos las llaves. Vamos a darle estilo con un color gris oscuro mediante un código. Ponemos color y el código que inicia con el símbolo de michi o numeral: seis cuatros, #444444, y punto y coma. Este es un color gris oscuro. Para el tamaño ponemos font-size: 16px;. Para cambiar el fondo de toda la página vamos a usar body, que representa todo el contenido visible de la página. Vamos a poner un color azul con background-color. En este caso es un azul clarito: escribimos el símbolo de michi y el código f0f4ff, seguido de punto y coma. Esperamos y se cambia el color. Además, vamos a colocar font-family para que el tipo de letra quede de manera general. Ponemos font-family, dos puntos, Arial y sans-serif. Así debería quedar: cambió el tipo de letra de toda la página. Ahora vamos a agregar algo nuevo en el HTML: un div, que es como una caja para agrupar contenido. En este caso la vamos a usar como una tarjeta. Dentro colocamos un subtítulo con h2 y un párrafo. A la caja le ponemos un nombre de clase: tarjeta. Debería quedar más o menos así: class="tarjeta". Colocamos el h2 que mencioné y escribimos «Esta es mi tarjeta». Cerramos la etiqueta y ponemos un párrafo que dice «Tiene un borde grueso y un fondo blanco». Cerramos la etiqueta div y ya debería quedar. Como viste, el contenido se pudo agregar. Antes de darle estilo, vamos a centrar el título para que se vea más ordenado. Vamos a la parte de h1 y usamos la propiedad text-align con el valor center. Esperamos y se centra. Ahora sí pasamos a la tarjeta. Como es una clase y no una etiqueta, vamos a escribir un punto antes del nombre: .tarjeta. Ese nombre debe ser exactamente igual al que está en el HTML; si no, no se va a producir ningún cambio. Colocamos las llaves. Dentro vamos a poner tres propiedades. Primero, background-color, para que tenga un fondo blanco, con el valor white. Luego ponemos border, que dibuja el borde de la tarjeta. Ahí indicamos el grosor, el tipo de línea y el color. Vamos a poner 12px, solid y el código del color, #2c3e90. Finalmente, width para el ancho: 300px, y punto y coma. Además, vamos a poner margin, que controla el espacio por fuera de la caja. Ponemos 10px auto, para que quede bien. Después agregamos padding, que da espacio por dentro de la caja, entre el borde y el contenido. Vamos a ponerle aproximadamente 20px y ya quedaría. Para resumir: margin es el espacio de afuera y padding es el espacio de adentro. Y con eso ya sabes más o menos cómo funciona CSS. Hemos elegido qué elemento modificar con un selector y, dentro de las llaves, escribimos las propiedades con sus valores. De esa manera termina esta minilección.
